# Infrastructure Monitoring

## Directory Structure

```
infra-monitor/
├── docker/
├── grafana/
├── prometheus/
├── mysql/
├── api/
├── web/
├── scripts/
├── docs/
└── tests/
```

Purpose:

- docker : Docker Compose dan container
- grafana : Dashboard Grafana
- prometheus : Prometheus configuration
- mysql : Database configuration
- api : Backend API
- web : Frontend
- scripts : Automation
- docs : Documentation
